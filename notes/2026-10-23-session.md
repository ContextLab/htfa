## BrainIAK reference findings (read src in scratchpad/ref)
- Factor: F[v,k] = exp(-||r_v - c_k||^2 / w_k), w = 2 sigma^2. C++ ext hardcodes 3D (no 2D support).
- C++ factor(): tmp1/tmp2/tmp3 declared OUTSIDE omp parallel for -> data race (bug).
- C++ recon(): `float tmp` accumulator (precision loss); residual = s*(X - FW) with s = std(X)/sqrt(2) (multiplies, doesn't divide).
- tfa.py: positional-arg order swaps between _fit_tfa_inner -> _estimate_centers_widths -> _residual_multivariate cancel out (correct by accident).
- tfa.py: np.random.choice(replace=False) with max_num_voxel; default TFA max_num_voxel=5000 errors if fewer voxels.
- htfa.py _assign_posterior: computes Hungarian col_ind but re-sets centers/widths UNPERMUTED; only cov/var permuted -> bug (mismatch).
- htfa.py: global template from ONE random subject (k-means on its R); centers cov = cov(R)*K^(-2/3); widths var = max_sigma; both scaled by 1/n_subj.
- Jacobian is '2-point' finite differences -> K*(D+1) full residual evals per Jacobian: main perf bottleneck. Analytic Jacobian = big win.
- PyPI name "htfa" is free.

## TFA init finding (2026-10-24)
- Synthetic 20^3, K=8, T=100, noise .1, standardize=False:
  - BrainIAK 0.12 TFA (KMeans on R, full data, max_iter 10): max center err 8.99/9.79/6.17 mm (seeds 0-2), median width rel err .11-.20, ~280 s per fit.
  - Ours w/ BrainIAK init: local minima (6.6-14.8 mm).
  - Ours w/ signal-power-weighted KMeans init (weights = clip(sum_t X^2 - median, 0)), widths = 2*weighted within-cluster mean sq dist / D, max_iter 30, threshold 1e-2: max center err 0.013-0.016 mm, width err 0.3%, ~4 s (seeds 0-3).
  - Same init with BrainIAK stopping (max_iter 10, threshold 1.0): stops at 3 iters, width err ~10%.
- Per-voxel z-scoring of synthetic data biases widths ~2.4x (noise voxels -> unit variance).
- User (2026-10-24): data-driven start OK if reproducible on real data; MUST verify inference moves estimates in the right direction.
- Weighted-power init: INIT max center err 0.11-0.91, width err ~45% -> FINAL 0.016 mm, 0.3%; final cost == truth-start cost (global optimum) on seeds 0-3.
- Caveat: per-voxel z-scoring makes power uniform -> power-weighting degenerates. Candidate z-score-invariant init: weight voxels by mean correlation with spatial neighbours.
- User (2026-10-24): z-scoring within voxel is REQUIRED on real data (raw fMRI dominated by anatomy); keep standardize default; design init for z-scored data.
- Neighbour-corr-weighted KMeans init on z-scored synthetic: works 3/4 seeds (seed2 init 7 voxels off). Plan: init='auto' = multi-start {ncorr-weighted, power-weighted, kmeans}, keep lowest final cost; init='kmeans' = BrainIAK.
- Basin of attraction (seed 0 data; sigma 1.16-2.18 vox; min sep 5.1 vox; ALL factors displaced in random directions; 4 trials each): 0.5σ & 1σ offsets with widths x0.5/x2 -> 4/4 recover to 0.016; 2σ -> 4/4 (x0.5), 2/4 (x2); 3σ -> 0/4, 1/4. => inference converges to truth from up to ~2σ away; init only needs to be within that basin.
- Codex consult (scratchpad/codex/q1.out): agrees with multi-start data-driven init (2014 TFA paper used hotspot init + random restarts), compare candidates on one full-data objective, scale-aware stopping w/ higher max_iter; z-scoring distortion inherent.
