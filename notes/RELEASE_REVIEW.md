## Follow-up scope

- Recursive NIfTI/image folders infer nested group templates and use folder
  names. `Subject.group_path` retains provenance. Explicit groups override
  inference; `groups=False` disables it. `GroupTree.from_paths` supports unequal
  depths and repeated names under different parents without artificial nodes.
- CUDA subject fits run concurrently across selected GPUs, with one queue per
  GPU. `gpu_devices` selects visible ordinals; `backend='cuda:N'` pins one GPU.
  `subject_engines_` reports actual device assignments. A single subject's
  factor model is not split across devices.
- Tutorial 05 compares K=5,20,80,160,320 on a 53×80 image, with narrower width
  bounds to represent finer detail. Its image-wide, in-sample R² rises from
  about .802 to .973 in the retained run.
- Every tutorial contains a figure and has a gallery card linking directly to
  its notebook. The PyPI badge appears only in README. A standalone quick-start
  guide covers synthetic fitting, inspection, plots, and real input folders.

## Independent review findings addressed

Fresh implementation agents and separate fresh reviewers examine the API,
scientific interpretation, documentation, figures, and gallery navigation.
Their fixes include ambiguous same-named folder ancestors, empty group-tree
outputs, optional notebook imports, and an explicit CUDA selection accidentally
probing an excluded GPU. Figure review corrects clipped markers and makes
animations display the files generated by the notebook instead of published
previews; machine/date printouts are absent from the public tutorial outputs. Complex initialization arrays now raise an error
instead of silently discarding imaginary values. Empty loader input produces
an actionable error.

Fitting and plotting support unequal-depth paths and repeated leaf names.
Permutation tests explicitly require equal-depth paths with distinct subgroup
labels under different parents. This does not require equal group sizes.
Independent subjects and label-independent initialization remain assumptions.
