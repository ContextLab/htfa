# Task 20: nested group hierarchy (Part 2 of the 2026-10-28 design)

Status: in progress (agent worktree agent-aac6f74f2eb9403e7).

Design choices
- `groups` and `subject_ids` are arguments of `HTFA.fit` (and `htfa.fit`), not
  constructor parameters (per-sample data, as sklearn's `groups`).
- Template tree: global (flat prior) -> groups level by level -> subjects. Every
  level uses the subject-level covariance Sigma; the templates minimizing the summed
  penalties solve A c = b (tree Laplacian + subject counts), independent of Sigma;
  posterior cov (A^-1)_vv Sigma. One-node tree = mean of local estimates = 'fixed'.
- Groups need template_update 'fixed' or 'empirical' ('brainiak' raises: its prior is
  its own previous posterior, not a parent). 'empirical' with groups: dispersion of
  deviations from each innermost group's median.
- Nesting: a label must belong to one parent label (crossed levels raise); with
  subject_ids, an id in two groups raises.
- Subjects matched to their innermost group template; groups in global order.
- Permutation test (htfa.groups.group_permutation_test): shuffle level-j labels among
  units (next-level groups or subjects) within each parent, refit with
  starts=free_fits_ and the same random_state; observed = refit with true labels;
  stats per factor: weighted RMS spread of group centers / log widths / Fisher-z
  connectivity rows; p = (1 + #null >= obs) / (1 + P); fwe=True max-statistic.
- No-groups path unchanged: scripts/validation_groups.py nogroups/compare vs 0948c13:
  150 arrays, 0 differ bitwise.
